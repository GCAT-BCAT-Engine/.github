# GCAT-BCAT-Engine

**GCAT-BCAT-Engine develops and applies GCAT/BCAT governed-transition and admissibility analysis.**

The organization contains the working engine family around formal evaluation, simulation, triage, publication, documentation, and reusable runtime components.

## What belongs here

Representative repositories include:

- **core-lite / core-lite-prod / core-full / core-addons** — executable engine layers;
- **StegSim** — scenario and transition simulation;
- **Triage** — classification and review support;
- **Publisher** — bounded document/publication output;
- **Documentation** — organization and formalism documentation;
- **workflows / telemetry** — supporting operational and evidence surfaces.

## Purpose

The organization exists to turn formal governance relationships into inspectable, testable, and reconstructable execution artifacts without collapsing validation into authority.

A successful test, simulation, publication, or CI run is evidence about that activity; it does not independently create admissibility, runtime authority, credentials, or downstream consequence authority.
